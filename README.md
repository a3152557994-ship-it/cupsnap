# 贴一杯 CupSnap — 奶茶咖啡拍照抠图贴纸日历

100% 纯免费、0 广告、免登录、全离线端侧运行的奶茶与咖啡贴纸手账日历。

- **在线网页即玩版 & 合规页**：https://a3152557994-ship-it.github.io/cupsnap/
- **Bundle ID**：`com.yanghe.cupsnap`（小组件 `com.yanghe.cupsnap.widgets`）
- **核心特性**：
  1. Apple Vision 离线 AI 前景抠图，1 秒将奶茶/咖啡杯照变成手工白边不干胶贴纸（支持白边/拍立得/邮票/和纸胶带 4 种边框 + 12 款手绘杯型）；
  2. Apple Vision 离线小票/外卖截图 OCR，内置 100+ 热门与地方小众品牌（含爷爷不泡茶、东方茉兰、霸王茶姬、瑞幸等），0.3 秒自动填品牌、饮品名、价格、糖度与冰度；
  3. 治愈系贴纸月历墙 + iOS 桌面小组件；
  4. 一键导出小红书 3:4 月度续命手账海报（3 套配色，无水印高清直出）；
  5. 一键 JSON 备份导出/恢复与 CSV 表格导出，换手机永不丢记录。
